# Python Data Analysis & Visualization

В этом разделе собраны мои проекты, выполненные на языке **Python**. Здесь я использую мощь библиотек для анализа данных и визуализации, чтобы находить закономерности, которые сложно заметить в обычных таблицах.

## Основные инструменты
*   **Pandas**: Очистка, фильтрация и агрегация больших наборов данных.
*   **Seaborn & Matplotlib**: Создание статистических графиков и кастомных визуализаций.
*   **Jupyter Notebook**: Оформление интерактивных отчетов с кодом и выводами.

## Список проектов

### 1. [Визуализация LTV по штатам Бразилии](./ltv_by_states)
Исследовательский анализ данных (EDA) на основе результатов SQL-запросов.
*   **Задача**: Визуализировать ценность клиентов (LTV) в разных регионах для поиска точек роста.
*   **Инструменты**: Pandas, Seaborn, Matplotlib.
*   **Результат**: Создан детализированный график с цветовым кодированием, выявлены штаты с максимальным чеком.
