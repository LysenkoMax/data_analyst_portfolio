# Анализ эффективности логистики и влияния качества сервиса на оценки клиентов

## 1. Описание бизнес-задачи
В сфере E-commerce скорость доставки является критическим фактором удержания клиентов. Цель данного исследования — провести аудит логистических процессов маркетплейса **Olist**, выявить географические зоны с аномально долгой доставкой и количественно измерить, как операционные задержки разрушают лояльность клиентов и влияют на рейтинг маркетплейса.

## 2. Как я решал задачу
Для анализа был реализован комплекс SQL-запросов, охватывающих три направления:
*   **Географический анализ**: Расчет среднего времени ожидания заказа по штатам Бразилии.
*   **Reliability Analysis (OTD)**: Оценка надежности доставки через расчет доли заказов, прибывших позже обещанного срока (Estimated Delivery Date).
*   **Sentiment Analysis**: Сопоставление факта задержки с оценками пользователей (`review_score`) для выявления прямой зависимости между логистикой и качеством сервиса.

## 3. С какими данными я работал
Использован датасет **Brazilian E-Commerce Public Dataset by Olist**. 
*   **Объем**: 100 000+ заказов за 2016–2018 гг.
*   **Ключевые таблицы**: `orders`, `customers`, `order_reviews`.
*   **Обработка**: Расчет временных интервалов производился через функцию `JULIANDAY`. Для корректности выводов по регионам была применена фильтрация штатов с количеством заказов < 100 (через `HAVING`).

## 5. Бизнес-выводы

### Географические барьеры
Анализ среднего времени доставки выявил критические задержки в удаленных регионах:
1. **RR (Рорайма)** - среднее время ожидания составляет **29.4 дня**.
2. **AP (Амапа)** - **27.2 дня**.
3. **AM (Амазонас)** - **26.4 дня**.
*Для сравнения: в центральных штатах (например, SP - Сан-Паулу) логистика работает почти в 5 раз быстрее.*

### Проблемы с точностью прогнозов
В некоторых штатах задержка является системной проблемой, а не случайностью:
*   В штате **AL (Алагоас)** задерживается **23.9% всех заказов** (почти каждый четвертый).
*   В штате **MA (Мараньян)** доля опозданий составляет **19.7%**.
Это указывает на необходимость пересмотра договоров с транспортными компаниями в данных регионах или корректировки алгоритма расчета «Обещанной даты доставки» для управления ожиданиями клиентов.

### Влияние на репутацию (Главный инсайт)
Исследование выявило катастрофическое влияние логистики на клиентский опыт:
*   **Заказы вовремя**: Средняя оценка - **4.29**. Доля негативных отзывов (1 звезда) - всего **6.6%**.
*   **Заказы с опозданием**: Средняя оценка падает до **2.56**. При этом **46.4% клиентов (почти каждый второй) ставят «1 звезду»**, если заказ задержан.

**Итоговый вывод**: Логистические сбои являются основным драйвером негативного опыта на платформе. Сокращение доли задержек в «проблемных» штатах (AL, MA) на 10% может существенно поднять общий рейтинг маркетплейса и снизить нагрузку на службу поддержки.
