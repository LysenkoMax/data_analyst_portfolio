## Описание проекта
Комплексный аналитический отчет для мониторинга операционных показателей компании. Дашборд позволяет отслеживать продажи в разрезе товарных категорий, сегментов покупателей и эффективности работы отделов продаж.

### Ключевые функции:
*   **ABC-анализ:** Автоматическая категоризация товаров по вкладу в общую выручку и прибыль компании.
*   **Customer Segmentation:** Анализ структуры покупателей (Consumer, Corporate, Home Office, Small Business).
*   **Geo-analytics:** Интерактивная карта распределения заказов и прибыли по регионам.
*   **Margin Control:** Детальный мониторинг заказов с отрицательной маржой в разрезе ответственных менеджеров.

---

## Технический стек
*   **Data Modeling:** Проектирование модели данных «Звезда» (Star Schema) для высокой производительности отчета.
*   **DAX:** Написание мер для расчета среднего чека, динамики прибыли (YoY/MoM) и гибкой логики категорий ABC.
*   **UI/UX:** Создание чистого интерфейса в корпоративном стиле с акцентом на ключевые отклонения.

---

## Бизнес-ценность
*   **Контроль маржинальности:** Позволяет быстро найти «проблемные» зоны и менеджеров с аномально высокой долей убыточных сделок.
*   **Складская логистика:** Помогает оптимизировать запасы на складе на основе ABC-анализа номенклатуры.
*   **Стратегический маркетинг:** Дает понимание самых прибыльных сегментов для более точной настройки рекламных кампаний.
