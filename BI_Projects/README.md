# Business Intelligence & Dashboarding

В этом разделе представлены мои проекты по созданию **интерактивных дашбордов**. Моя цель - переводить сложные расчеты из SQL и Python на язык визуальных образов, понятный топ-менеджменту и бизнес-заказчикам.

## Основные инструменты
*   **Looker Studio (Google Data Studio)**: создание облачных интерактивных отчетов с подключением к Google Sheets/BigQuery.
*   **Power BI**: (в процессе изучения) проектирование сложных аналитических моделей.
*   **Data Storytelling**: умение выделять главные KPI и акцентировать внимание на аномалиях через визуализацию.

---

## Список BI проектов

### 1. [Интерактивная карта LTV по штатам Бразилии](ltv_by_state)
Визуализация региональной ценности клиентов на основе реальных данных маркетплейса Olist.
*   **Инструмент**: Looker Studio.
*   **Задача**: Наглядно показать географическое распределение прибыли и выявить "золотые" регионы с самым высоким средним чеком.
*   **Что внутри**: Интерактивная карта, сводные карточки (Scorecards) и детализированная таблица показателей.

---

## Ключевые навыки в BI
1.  **ETL**: Подготовка и чистка данных перед визуализацией.
2.  **UI/UX для данных**: Проектирование понятных интерфейсов, где важные цифры всегда на виду.
3.  **Geo-analytics**: Работа с географическими картами и распределением показателей по регионам.
